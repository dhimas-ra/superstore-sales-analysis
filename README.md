# Superstore Sales & Profitability Analysis (2011–2014)

Proyek analitik data menggunakan **SQLite** (dikelola via DBeaver) dan divisualisasikan menggunakan **Google Sheets** untuk mengevaluasi kinerja bisnis, tren regional, serta dampak diskon terhadap profitabilitas perusahaan retail Superstore.

## 📊 Key Insights & Visualizations
Berikut adalah hasil temuan utama dari analisis yang dilakukan:
* **Tren Kategori Produk:** Kategori *Technology* menunjukkan pertumbuhan pendapatan yang paling konsisten dari tahun ke tahun dibandingkan *Furniture* dan *Office Supplies*.
* **Analisis Diskon ("Bakar Uang"):** *Scatter plot* membuktikan bahwa rata-rata diskon yang terlalu tinggi pada beberapa sub-kategori berdampak langsung pada kerugian (*profit* minus).
* **Pemetaan Segmen & Wilayah:** Pelanggan segmen *Consumer* mendominasi total *sales* di hampir seluruh wilayah regional.

## 🛠️ Tech Stack
* **Database / Query:** SQLite, DBeaver
* **Visualisasi & Dashboard:** Google Sheets (Pivot Table, Line Chart, Stacked Bar, Scatter Plot)
